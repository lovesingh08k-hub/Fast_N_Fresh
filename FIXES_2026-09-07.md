# Fast N Fresh — fixes for 2026-09-07

- Customer QR menu no longer restores stale UPI payment state on a fresh QR scan. UPI attempts are tied to the active browser session and table.
- UPI API errors now expose HTTP status so invalid tracking records can be cleared safely.
- Flutter theme switching uses a smooth Material theme animation.
- Products search is debounced and also searches the backend, so it is not limited to the initially loaded product list.
- Customer menu config uses the verified production public-menu API.
- Breakfast/Biryani migration is included. Run `cd backend` then `npm run migrate:breakfast-biryani` to apply the poster items to the database.
- Kitchen action row uses responsive wrapping to avoid button overflow.

Build after extraction:

```powershell
cd mobile
flutter clean
flutter pub get
flutter analyze
flutter build apk --release
```

The release signing files are intentionally not included in this ZIP. Restore your own secure `android/key.properties` and machine-specific `android/local.properties` if your local setup requires them.
